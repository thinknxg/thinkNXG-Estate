# thinkNXG Estate

**Property Management, Leasing and Real Estate CRM** — *One Platform. Every Property. Complete Control.*

thinkNXG Estate is one installable app for thinkNXG ERP (Framework v16 + ERP v16). It brings
together what used to be four separate apps (`re_core`, `re_crm`, `re_portal`, `re_voice`)
under one install, one navigation, one role model and one data model.

| Module | What it covers |
|---|---|
| Estate Property | Properties, units, owners, amenities, photos, documents, utility accounts |
| Estate Leasing | Tenants and KYC, lease contracts (submittable), charges, move-in/out inspections |
| Estate Finance | Rent schedules and installments, rent invoicing (Sales Invoice), PDCs, security deposits, bulk rent payments, credit balances, owner statements, property expenses |
| Estate Maintenance | Maintenance requests and jobs (vendor or in-house, billable or not) |
| Estate CRM | Leads with property matching, deals (kanban pipeline), site visits, reservations, agents and brokers with targets, commission plans and entries, lead ownership, WhatsApp messaging, communication history |
| Estate Portal | Public listings (`/properties`, `/property/<route>`, `/listings`) with viewing requests, enquiries, AI listings chat, tenant portal (`/tenant-portal`), owner portal (`/owner-portal`), Property Finder / Bayut feeds |
| Dashboard and reports | Filtered live dashboard (`/app/estate-dashboard`) and 18 reports across finance, leasing, property, CRM, maintenance and voice |
| Estate Voice | WhatsApp voice-first CRM: voice commands, ASR + translation, intent engine, lead scoring, sentiment, customer threads |

## Install (new site)

```bash
bench get-app <thinkNXG Estate repository URL> --branch version-16
bench --site SITE install-app thinknxg_estate
bench --site SITE migrate
bench build --app thinknxg_estate
```

Complete the thinkNXG ERP setup wizard before or after installing; the rent item
("Rental Charge") is created as soon as Item Groups exist.

Then open **Property Settings** (rent item, invoice lead days, deposit accounts),
**RE CRM Settings**, **RE Portal Settings** and, if used, **WhatsApp Settings** and **AI Settings**.

## Upgrade a site running re_core / re_crm / re_portal / re_voice

The upgrade is in place: no data is copied or moved, DocType names and tables stay the same.

```bash
bench --site SITE backup --with-files          # always take a backup first
bench get-app <thinkNXG Estate repository URL> --branch version-16
bench --site SITE install-app thinknxg_estate  # detects and migrates the legacy apps
bench --site SITE migrate
bench remove-app re_voice && bench remove-app re_portal && bench remove-app re_crm && bench remove-app re_core
```

Never run `bench uninstall-app` on the legacy apps: uninstalling deletes DocTypes by module.
The installer detaches them from the site for you. See `docs/MIGRATION.md` for what the
upgrade changes and how to roll back.

Existing integrations keep working: every legacy `/api/method/re_*` URL (desk scripts, the
tenant client, the Meta WhatsApp webhook, Property Finder / Bayut feed URLs) is routed to the
unified implementation.

## Required site config for WhatsApp

```json
{ "whatsapp_app_secret": "<Meta app secret>", "whatsapp_verify_token": "<long random string>" }
```

Webhook URL: `https://SITE/api/method/thinknxg_estate.voice.api.webhook.webhook`

## Tests

```bash
bench --site TEST_SITE set-config allow_tests true
bench --site TEST_SITE run-tests --app thinknxg_estate
python3 -m pytest thinknxg_estate/tests/unit   # framework-free logic tests
```
